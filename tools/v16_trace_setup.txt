# DOSBox-X Debugger Script for Genpei Gassen AI Dispatch Tracing
# Usage: 在 DOSBox-X 调试器中逐行粘贴，或用 `source` 命令加载

# ============================================================
# 1. 设置关键断点
# ============================================================

# 外层 VM 取指循环 - 每条指令执行前断下
bp 0x31CA:0x7CBC
# 真正分发指令
bp 0x31CA:0x7CC3

# Task 0x08 描述符被读取时 (DS:0x92F8 = 物理 0x6ACF8)
bpr 0x6ACF8
bpw 0x6ACF8

# 惰性解析器入口
bp 0x31CA:0x7C41
# 解析器 miss 路径
bp 0x31CA:0x7C53

# AI VM 操作码表基址被访问
bpr 0x220D0
bpr 0x220E0  # opcode 0x08 入口

# ============================================================
# 2. 条件断点辅助：记录 task ID 值
# ============================================================
# 在 VM_FETCH 处，检查 AL (opcode) 是否为 0x08
# DOSBox-X 不直接支持条件断点，需手动检查：
#   bp 0x31CA:0x7CBC
#   运行到断点 -> r -> 查看 AL

# ============================================================
# 3. 自动跟踪日志
# ============================================================
log v16_trace.log
# 可选：只记录关键区域
# trace 1000  # 单步 1000 条指令

# ============================================================
# 4. 关键内存监视
# ============================================================
# DS:0x5B90 (模块计数) = 0x619F0+0x5B90 = 0x67580
# DS:0x5B92 (段缓存) = 0x619F0+0x5B92 = 0x67582
# 监视 AI 模块索引的缓存写入
bpw 0x67582

# ============================================================
# 5. 运行建议流程
# ============================================================
# 1. 游戏启动到标题画面
# 2. 开始新游戏 / 进入对局
# 3. 等待轮到 AI 行动 (观察日志中 task 0x08 被读取)
# 4. 断点命中顺序预期：
#    a) bpr 0x6ACF8 (读取 task 0x08 描述符)
#    b) bp 0x31CA:0x7CBC (VM 取指，AL=0x08)
#    c) bp 0x31CA:0x7CC3 (分发到 task 0x08 handler)
#    d) bp 0x31CA:0x7C41 (handler 调用解析器，BX=AI_idx)
#    e) bp 0x31CA:0x7C53 (解析器 miss，加载 AI 模块)
#    f) bpw 0x67582 (缓存 AI 段值 0x220D|1)
#    g) bpr 0x220D0 (进入 AI VM，读取操作码表)
#    h) 后续 AI VM 执行...

# ============================================================
# 6. 寄存器关注点
# ============================================================
# 在解析器入口 (0x398E1):
#   BX = 模块索引 (应为 AI 模块的索引)
#   SI = 返回地址 (调用者的后续指令)
# 在解析器返回 (jmp si 前):
#   DX = 模块数据段 (应为 0x220D 或 AI 数据段)
#   AX/DI = 近偏移入口 (cs:0x22C6 表值)
# AI VM 启动时:
#   CS = 0x220D
#   SI = 字节码流指针 (AI 脚本数据区)

# ============================================================
# 导出追踪后分析
# ============================================================
# grep -n "0x6ACF8\|0x7CBC\|0x7CC3\|0x7C41\|0x7C53\|0x220D" v16_trace.log
# 关注 BX/AX/DX/SI/DI/CS/DS 变化
